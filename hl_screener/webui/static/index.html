Paper

      
Follow the shortlist live, with no money

      
One virtual account per leader. Every trade the leader makes arrives over Hyperliquid's public feed; the follower's order is priced by walking the real order book at that moment, pays taker fees and hourly funding. Nothing is sent to the exchange. Measured slippage and latency sit next to what the screen's model assumed, which is the point: it tells you whether the screen's numbers were true.

Design

      
Built from a DESIGN.md

      
This page is styled from design/DESIGN.md, the Linear-inspired system in the awesome-claude-design collection. The file's front matter (colours, type scale, radii, spacing, components) is projected into tokens.css; every component on this page reads those tokens and nothing else.

    

    

      

        
Swap the design system

        

          
    
            
  1. Pick a system in the collection and open its preview on getdesign.md.
    2. 
            
  2. Save its DESIGN.md over design/DESIGN.md (raw files live at VoltAgent/awesome-design-md/design-md/<slug>/DESIGN.md).
    3. 
            
  3. Re-derive hl_screener/webui/static/tokens.css from the new front matter, keeping the same variable names. Reload this page.
    4. 
          

          
The same file can be uploaded to Claude Design ("Create new design system") to get a full kit, and pasted into a Claude Code session as the brief for any new screen.
